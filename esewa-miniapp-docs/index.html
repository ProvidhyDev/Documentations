Using this site

  • Unzip the download and open index.html in any browser - every page works offline; diagrams load from a CDN the first time.
  • On any document page, press Export PDF, tick the sections you want, then Export as PDF - choose "Save as PDF" in the print dialog to keep a copy on your phone.
  • Use the sidebar filter (or the menu button on mobile) to jump between documents and sections.
