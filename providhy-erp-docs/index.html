Using this site

  • Every service starts from its Overview page: authentication model, functional clusters, and a page map.
  • Citations are file:line references into the f1-production repos at the SHA in each page frontmatter.
  • Rows marked unverified are inferred from structure, not read line-by-line; excluded features (GRN, product variants, transaction-linked journals) are listed with one line only.
  • Use the sidebar filter to jump between services and pages.
